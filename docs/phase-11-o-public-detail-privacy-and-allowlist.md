# Privacidad y Lista Blanca de Detalle Jurisprudencial (Fase 11.O)

## Campos Renderizables Únicos (Lista Blanca)
1. `slug`
2. `title`
3. `caseNumber`
4. `resolutionNumber`
5. `resolutionType`
6. `institutionName`
7. `issuingBody`
8. `matter`
9. `issuedAt`
10. `summary`
11. `sourceName`
12. `sourceDocumentId`

## Protección de Datos Internos
Se garantiza la omisión absoluta de:
* Identificadores internos (`recordId`, `projectionId`, `authorizationCaseId`).
* Versiones y revisiones (`recordVersion`, `publicRevision`).
* Notas editoriales privadas, consultas SQL y trazas de auditoría.
