# Privacidad y lista blanca 11.L

La lista blanca validada se limita a identificadores públicos, identidad jurisprudencial aprobada, metadatos descriptivos, resumen público, fuente pública y estado/revisión del read model. El esquema estricto rechaza campos desconocidos e internos.

No se implementa anonimización automática ni se afirma aprobación legal. Derechos y privacidad deben estar previamente aprobados por 11.I. No se incorporaron fuentes o registros jurídicos reales y los logs no reciben contenido jurídico, datos personales, hashes, SQL, paths, tokens o secretos.

SRV-WEB-001 conserva `allowsImmediatePayment: false` y `published: false`. BL-LEG-CON-001 conserva `editorial_preview`, precio y moneda nulos, licencia pendiente, autorización de publicación falsa y todos sus archivos sin descarga pública autorizada.
