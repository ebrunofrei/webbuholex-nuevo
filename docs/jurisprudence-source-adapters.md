# Adaptadores de fuentes jurisprudenciales

Fuentes institucionales iniciales: Poder Judicial del Perú, Tribunal Constitucional del Perú, Corte Interamericana de Derechos Humanos y SPIJ. Cada institución conserva identidad separada; no se utiliza un campo `author` para representar órganos.

Orden de prioridad:

1. API oficial.
2. Dataset oficial abierto.
3. Documento oficial.
4. Página oficial estable.
5. Enlace oficial manual.

Todos los adaptadores están deshabilitados. No contienen credenciales, endpoints privados ni rutas de almacenamiento. La política prohíbe scraping activo, elusión de CAPTCHA, proxies evasivos, descarga masiva repetida y sobrecarga de portales.

Antes de habilitar una fuente se deberá verificar autorización, estabilidad, límites de uso, URL canónica, procedencia institucional y mecanismo de actualización.
