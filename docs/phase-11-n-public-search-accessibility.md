# Fase 11.N — Accesibilidad

La experiencia mantiene un único `main` y un único `h1`. Los controles tienen etiquetas visibles, el campo principal vincula ayuda y error mediante `aria-describedby`, y los resultados, carga y errores se anuncian con regiones vivas.

Los botones tienen nombres accesibles, el foco global visible se conserva y la navegación no depende del color. La paginación usa un `nav` etiquetado. La grilla aplica `minmax(0, 1fr)`, controles de ancho completo y reorganización móvil para evitar desbordamiento horizontal en 360, 390, 430, 768, 1024 y 1280 píxeles.

La validación material en esos viewports fue verificada en la validación técnica externa ejecutada y acreditada.
